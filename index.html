Qu'est-ce que Nilo ?

Une application desktop de gestion de projets qui fonctionne « out of the box » : quatre vues par projet, et vos données stockées dans un simple dossier.

Kanban

Glissez-déposez vos tâches entre les colonnes. Filtres par priorité et tags, tri à la volée.

Vue liste

Toutes vos tâches groupées par statut, avec filtres, tri et ajout rapide inline.

Gantt interactif

Des barres déplaçables et redimensionnables en temps réel pour planifier vos échéances.

Stockage local

Un vault SQLite dans le dossier de votre choix, inspiré d'Obsidian. Zéro cloud, zéro compte : vos données restent chez vous, toujours.

Calendrier

Une vue mensuelle des échéances, projet par projet, pour ne rien laisser passer.

Sous-tâches

Subdivisez vos tâches avec des cases à cocher et suivez la progression d'un coup d'œil.

Le concept

Vos données, dans un simple dossier

Avec Nilo, vous choisissez un dossier. L'application y crée une base SQLite (nilo.db) et c'est tout : vous travaillez. Rien n'est envoyé sur Internet.

Un vault par client, par équipe, sur une clé USB ou un NAS… peu importe. Nilo fonctionne entièrement hors-ligne, sans aucune dépendance réseau.

  • Multi-vault et multi-projets, chacun avec sa couleur
  • Aucune inscription, aucune donnée envoyée en ligne
  • Léger et rapide, construit avec Tauri (Rust + React)
  • Installeur classique ou version portable

FAQ

Questions fréquentes

Où sont stockées mes données ?

Uniquement sur votre machine, dans le dossier (« vault ») que vous choisissez. Nilo y crée une base SQLite nilo.db. Rien n'est envoyé sur Internet.

Ai-je besoin d'un compte ou d'une connexion ?

Non. Aucun compte, aucune inscription. Nilo fonctionne entièrement hors-ligne.

Sur quels systèmes Nilo fonctionne-t-il ?

La beta publique actuelle est disponible pour Windows 10/11 (64 bits), en installeur ou en version portable.

Windows affiche un avertissement au lancement, est-ce normal ?

Oui. Les exécutables ne sont pas encore signés, donc SmartScreen peut afficher un avertissement. Cliquez sur « Informations complémentaires » puis « Exécuter quand même ».

Quelle est la différence entre l'installeur et la version portable ?

L'installeur place Nilo dans votre dossier utilisateur avec un raccourci. La version portable se lance directement, sans installation — pratique sur une clé USB.

Comment recevoir les mises à jour ?

Les nouvelles versions sont publiées sur GitHub Releases. Suivez le dépôt pour être notifié à chaque sortie.
