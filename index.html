Le concept

Inspiré du modèle « vault » d'Obsidian

Avec Nilo, vous choisissez un dossier. L'application y crée une base SQLite (nilo.db) et c'est tout : vous travaillez. Vos données ne quittent jamais votre machine.

Un vault par client, par équipe, sur une clé USB ou un NAS… peu importe. Nilo fonctionne entièrement hors-ligne, sans aucune dépendance réseau à l'exécution.

  • Multi-vault et multi-projets, chacun avec sa couleur
  • Aucune inscription, aucune donnée envoyée en ligne
  • Mode sombre automatique selon votre système
  • Léger et rapide, construit avec Tauri (Rust + React)

FAQ

Questions fréquentes

Où sont stockées mes données ?

Uniquement sur votre machine, dans le dossier (« vault ») que vous choisissez. Nilo y crée une base SQLite nilo.db. Rien n'est envoyé sur Internet.

Ai-je besoin d'un compte ou d'une connexion ?

Non. Aucun compte, aucune inscription. Nilo fonctionne entièrement hors-ligne.

Sur quels systèmes Nilo fonctionne-t-il ?

La beta publique actuelle est disponible pour Windows 10/11 (64 bits), en installeur ou en version portable.

Windows affiche un avertissement au lancement, est-ce normal ?

Oui. Les exécutables ne sont pas encore signés, donc SmartScreen peut afficher un avertissement. Cliquez sur « Informations complémentaires » puis « Exécuter quand même ».

Quelle est la différence entre l'installeur et la version portable ?

L'installeur place Nilo dans votre dossier utilisateur avec un raccourci. La version portable se lance directement, sans installation — pratique sur une clé USB.

Comment recevoir les mises à jour ?

Les nouvelles versions sont publiées sur GitHub Releases. Suivez le dépôt pour être notifié à chaque sortie.
