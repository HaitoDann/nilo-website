FAQ

Questions fréquentes

Nilo est-il vraiment gratuit ?

Oui, Nilo est entièrement gratuit et sans engagement. Aucune carte bancaire n'est requise.

Sur quels systèmes puis-je l'installer ?

Nilo est disponible sur Windows, macOS et Linux. Rendez-vous sur la page de téléchargement pour la version qui correspond à votre système.

Comment installer l'application ?

Téléchargez le fichier correspondant à votre système depuis GitHub Releases, puis lancez-le. L'installation ne prend que quelques secondes.

Comment recevoir les mises à jour ?

Les nouvelles versions sont publiées sur GitHub Releases. Vous pouvez suivre le dépôt pour être notifié à chaque sortie.
